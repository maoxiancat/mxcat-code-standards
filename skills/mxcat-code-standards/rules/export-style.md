# 导出规范

## 适用范围

- 目标范围内的集中导出文件，如 `index.ts`、`index.tsx`、`index.js`、`index.jsx`
- 其他以“集中导出”为职责的 barrel 文件

## 执行原则

- 仅改 `export` 相关顺序、分组、空行与格式
- 无特殊要求时，不改变业务语义、不新增/删除导出成员。
- 保持最小 diff。

## 规则

1. 按声明形态分层

- 单行 `export` 在前。
- 多行 `export` 在后。
- 单行与多行之间保留 1 个空行。

2. 各形态内按命名风格分组

- 按成员命名风格分组，组间保留 1 个空行。
- 分组顺序：`PascalCase` -> `camelCase` -> `UPPER_SNAKE_CASE`。
- 单行 `camelCase export` 仍在多行 `PascalCase export` 之前，不能为命名分组跨越形态分区。

3. 单行 `export` 行排序

- 仅在同一形态、同一命名风格组内，按整行字符长度从长到短排序。

4. 多行 `export` 规则

- 每个多行块内部成员按成员名长度从长到短排序。
- 同一命名风格组内的多行块保持原有相对顺序，不按整个块的长度排序。

5. 单行成员规则

- 单行 `export { ... }` 内成员按成员名长度从长到短排序。
- 长度相同按字母序（A-Z）排序。
